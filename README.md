# Student Task Manager

A responsive web application built with HTML, CSS, and JavaScript to help university students organize their study tasks and deadlines.

## Preview

![Student Task Manager screenshot](screenshots/task-manager.png)

## Features

- **Add tasks:** Create tasks with a name and deadline.
- **Complete tasks:** Mark tasks as completed or undo completion.
- **Delete tasks:** Remove tasks you no longer need.
- **Filter tasks:** View all, pending, or completed tasks.
- **Task counter:** Display the total number of saved tasks.
- **Persistent storage:** Keep tasks and completion status after refreshing the browser using localStorage.
- **Responsive design:** Use the application on desktop and smaller screens.
